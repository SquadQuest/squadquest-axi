# squadquest-axi

Agent-ergonomic CLI for [SquadQuest](https://squadquest.app) — see what your friends are up to, post events, and rally a squad from the terminal.

Built to the [AXI](https://github.com/JarvusInnovations/axi) standard: token-efficient TOON output, minimal default schemas, structured errors, and contextual next-step hints so an agent discovers the surface area by using it.

> [!NOTE]
> Early development. The command surface is still settling — see [`specs/`](specs/README.md) for what it's meant to do and [`plans/`](plans/README.md) for what's in flight.

## Install

```sh
npm install -g squadquest-axi
```
